# Quantum Timeline

List last commits, stashes and worktrees in SCM tab. No need for git log, git stash, quick overview for current repository.

## Features

- List last commits
- Quickly undo last commit
- Preview commit changes (diff files)
- Revert file changes
- Easily copy commit hash and file path
- List all stashes
- Apply, pop, drop and create stashes
- Manage remotes
