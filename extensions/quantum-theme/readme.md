# Quantum Theme

Color themes and a custom file icon set for the Quantum editor.

## Color themes

| Theme | Use |
|-------|-----|
| **Quantum Dark** | Default dark theme — Nord-inspired palette, semantic highlighting |
| **Quantum Light** | Light UI for bright environments |
| **Quantum High Contrast** | Accessibility-focused, maximum contrast |

## Icon theme

**Quantum Icon Theme** — file and folder icons for common languages, frameworks, and tools.

## Installation

1. Open your editor
2. Extensions → search **Quantum Theme**
3. Install, then pick a color theme and icon theme under Preferences

## Customization

Override colors in `settings.json`:

```json
{
  "workbench.colorCustomizations": {
    "[Quantum Dark]": {
      "editor.background": "#1a1a1a"
    }
  }
}
```
