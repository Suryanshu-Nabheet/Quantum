# Quantum built-in extensions.

First-party Quantum extensions bundled into Quantum release builds.

| Directory | Purpose |
|-----------|---------|
| `quantum-theme/` | Quantum Dark/Light themes, file icons, product icon font |
| `quantum-emulator/` | Android emulator launcher integration |
| `quantum-error-lens/` | Inline diagnostics styling |
| `quantum-pdfviewer/` | In-editor PDF preview |
| `quantum-project-tree/` | Project tree / structure generator |
| `quantum-timeline/` | Git timeline view |
