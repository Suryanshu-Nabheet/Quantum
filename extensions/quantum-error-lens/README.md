# Quantum Error Lens

Quantum ErrorLens turbo-charges language diagnostic features by making diagnostics stand out more prominently, highlighting
the entire line wherever a diagnostic is generated by the language and also prints the message inline.

## Features

- **Highlight lines containing diagnostics** - Visual emphasis on problematic code
- **Append diagnostic as text to the end of the line** - See error messages directly in your code
- **Show icons in gutter** - Quick visual indicators in the editor margin
- **Show message in status bar** - Keep track of errors at a glance
- **Customizable severity levels** - Choose which diagnostic levels to display (error, warning, info, hint)
- **Rich customization options** - Control fonts, colors, spacing, and more
- **Status bar integration** - Display error counts and messages in the status bar
- **Code Lens support** - Interactive error information above your code
- **Search for problems** - Quick web search for error messages
- **Exclude patterns** - Fine-tune what gets highlighted

## Configuration

Quantum Error Lens offers extensive customization through the `quantumErrorLens.*` settings:

### Basic Settings

- `quantumErrorLens.enabled` - Enable/disable the extension
- `quantumErrorLens.enabledDiagnosticLevels` - Choose which severity levels to show
- `quantumErrorLens.messageTemplate` - Customize how error messages are displayed

### Visual Customization

- `quantumErrorLens.fontFamily`, `quantumErrorLens.fontSize`, `quantumErrorLens.fontWeight` - Typography controls
- `quantumErrorLens.margin`, `quantumErrorLens.padding`, `quantumErrorLens.border` - Spacing and borders
- `quantumErrorLens.messageBackgroundMode` - How to highlight (line/message/none)
- `quantumErrorLens.severityText` - Custom icons for different severity levels

### Status Bar

- `quantumErrorLens.statusBarMessageEnabled` - Show messages in status bar
- `quantumErrorLens.statusBarIconsEnabled` - Show error/warning icons in status bar
- `quantumErrorLens.statusBarColorsEnabled` - Use colors in status bar

### Advanced Features

- `quantumErrorLens.gutterIconsEnabled` - Show icons in the gutter
- `quantumErrorLens.codeLensEnabled` - Enable Code Lens integration
- `quantumErrorLens.excludePatterns` - Exclude files by glob patterns
- `quantumErrorLens.transmute` - Customize decoration for specific problems

## Commands

Access Quantum Error Lens commands through the Command Palette (Ctrl+Shift+P / Cmd+Shift+P):

- `Quantum Error Lens: Toggle (Enable/Disable) Everything` - Master toggle
- `Quantum Error Lens: Toggle Errors/Warnings/Info/Hint` - Individual severity controls
- `Quantum Error Lens: Toggle Inline Message` - Show/hide inline messages
- `Quantum Error Lens: Search for problem` - Web search for current error
- `Quantum Error Lens: Select Problem` - Jump to problem location
- `Quantum Error Lens: Copy Problem Message` - Copy error to clipboard
- `Quantum Error Lens: Disable Line` - Add linter disable comment
- `Quantum Error Lens: Find Linter Rule Definition` - Jump to rule configuration

## Message Template

Customize error display using variables:
- `$message` - Diagnostic message text
- `$severity` - Severity icon from `quantumErrorLens.severityText`
- `$source` - Diagnostic source (e.g., "eslint", "typescript")
- `$code` - Diagnostic code
- `$count` - Number of diagnostics on the line

Example template: `[$severity] $message ($source)`

## Exclusion Patterns

Fine-tune what gets highlighted:

```json
{
  "quantumErrorLens.excludeBySource": ["eslint", "typescript"],
  "quantumErrorLens.excludeByMessage": ["TODO", "FIXME"],
  "quantumErrorLens.excludePatterns": ["**/*.test.ts", "**/node_modules/**"]
}
```

## Status Bar Integration

The status bar can show:
- Error and warning counts with customizable icons
- Current error message at cursor position
- Clickable actions (go to problem, copy message, etc.)

## Code Lens

When enabled, Quantum Error Lens adds interactive Code Lens items above problematic code, providing quick access to common actions like searching for solutions or viewing quick fixes.

## Performance

Quantum ErrorLens is optimized for performance:
- Debounced updates to reduce UI thrashing
- Configurable delays before showing decorations
- Efficient diagnostic processing
- Minimal impact on editor responsiveness
