# Getting Started with Quantum

Quantum is an open source, AI-native code editor created by **Suryanshu Nabheet**, built on Visual Studio Code under the MIT license.

## Installation

Build from source (see [howto-build.md](howto-build.md)) or install from [GitHub Releases](https://github.com/Suryanshu-Nabheet/Quantum) when available.

## First Steps

1. **Open a folder**: File → Open Folder
2. **Install extensions**: Extensions sidebar (Open VSX by default)
3. **Configure settings**: File → Preferences → Settings

## What Makes Quantum Different

- Branded as an **AI-first** open source editor
- **No Microsoft telemetry** by default
- **Open VSX** extension marketplace
- MIT-licensed build pipeline maintained at [Suryanshu-Nabheet/Quantum](https://github.com/Suryanshu-Nabheet/Quantum) (`quantum/`)

## Keyboard Shortcuts

- `Ctrl+P` / `Cmd+P`: Quick Open
- `Ctrl+Shift+P` / `Cmd+Shift+P`: Command Palette
- `Ctrl+,` / `Cmd+,`: Settings
