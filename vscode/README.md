# Quantum VS Code customizations.

First-party workbench changes in `ide/` that are not covered by `build/` or `extensions/`.

| Folder | Purpose |
|--------|---------|
| [`onboarding/`](onboarding/README.md) | First-run onboarding flow |
| [`titlebar/`](titlebar/README.md) | Title bar layout quick menu |
| [`editor-watermark/`](editor-watermark/README.md) | Empty-window welcome UI |
| [`layout/`](layout/README.md) | Workbench layout tweaks |
| [`theme-defaults/`](theme-defaults/README.md) | Default Quantum theme and icon theme IDs |
| [`product/`](product/README.md) | `product.json` onboarding config |

Paths under each folder mirror `ide/src/vs/...` unless noted in that folder’s README.
